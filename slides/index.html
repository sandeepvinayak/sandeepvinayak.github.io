Self Managed
Definition11

Self Managed Services

A model where the organization is responsible for the entire lifecycle — installation, configuration, maintenance, scaling, and security. The cloud provider only provides raw building blocks.
Ex.
Installing Apache Cassandra on a VM, tuning the JVM, managing replication factors, patching the OS, and manually scaling nodes
NIST
Referred to under the Infrastructure as a Service (IaaS) model. Provider manages physical hardware and virtualization; everything inside the VM is self-managed.
Source: NIST SP 800-145 — The NIST Definition of Cloud Computing

Inevitable15

Provider Managed Services are Inevitable

Why Provider Managed Services are essential and irreplaceable:
Timelines & Feature Gaps
Core Services: Lack of support for abstractions (Compute, ECR, DNS)
Architectural Constraints: Risks of cyclic dependencies
Cross-service integrations: S3 → SQS/SNS, Step Functions → SQS
Availability/SLA: S3 has 11 9s of durability

Most importantly: Several self-managed services internally might use the provider managed services

Design20

Key Principles of MultiCloudJ

Principle 1
Cloud Neutral
Enables write once, deploy anywhere. No provider-specific code in your application.
Principle 2
Flexibility
Users can customize the provider implementation for their special use-cases.
Principle 3
Extensibility
Interfaces can be extended with additional cloud providers seamlessly.
Principle 4
Uniform Semantics
Provider semantics differences are handled by the SDK — users get a single, consistent API.

Comparison23

Code: AWS S3 vs MultiCloudJ

AWS S3 Direct
// Initialize
S3Client s3 = S3Client.builder()
    .region(Region.US_EAST_1)
    .build();

// PUT OBJECT
s3.putObject(
    PutObjectRequest.builder()
        .bucket("my-bucket")
        .key("example-key.txt")
        .build(),
    RequestBody.fromString("Hello"));

// GET OBJECT
ResponseBytes<GetObjectResponse> obj =
    s3.getObjectAsBytes(
        GetObjectRequest.builder()
            .bucket("my-bucket")
            .key("example-key.txt")
            .build());
byte[] data = obj.asByteArray();
MultiCloudJ
// Initialize
BucketClient client = BucketClient.builder("aws")
    .withBucket("my-bucket")
    .withRegion("us-east-1")
    .build();

// PUT OBJECT
UploadRequest uploadReq = UploadRequest.builder()
    .key("example-key.txt")
    .build();
client.upload(uploadReq, "Hello!".getBytes());

// GET OBJECT
DownloadRequest downloadReq = DownloadRequest.builder()
    .key("example-key.txt")
    .build();
ByteArray result = client.download(downloadReq, new ByteArray());
byte[] data = result.getArray();

A purpose-built MCP server, packaged in a Claude plugin with skills, that turns provider-specific code into cloud-agnostic MultiCloud SDK code in hours, not days.
